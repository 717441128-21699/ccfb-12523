# 地铁报站音频编排系统

地铁新线开通前的报站音频生产工具：把录好的站名、线路号、换乘提示等词条，按模板自动拼接成整句中英文广播，支持试听审核、噪声模型评估、临时运营图与批量出包。前端纯 TypeScript（React + Vite），音频处理全部在浏览器内完成，无需后端。

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm test           # 17 个单元测试（拼接阈值 / 编译 / 清晰度 / 出包）
npm run build      # 类型检查 + 生产构建
npm run lint       # oxlint
```

## 五大页面

| 页面 | 职责 |
| --- | --- |
| 词条库 | 同一站名按**句首 / 句中 / 句尾三种语调**各一条；默认合成假词条，可上传真实录音逐条替换（自动单声道化 + 重采样到 24kHz） |
| 线路配置 | 车站序列排序、换乘线路号、逐站停站时间（广播时长校验基准） |
| 模板编排 | `{{station}} / {{nextStation}} / {{line}} / {{transfer}}` 变量拼句，中英文两套；实时分词预览与单模板试拼 |
| 试听审核 | 全线编译、逐条试听、**超停站时间整行标红**、拼接点质检、车厢噪声叠加试听与清晰度指数（AI） |
| 临时运营图 | 甩站 / 改线计划，**按生效时段**生成临时广播；过期、停用自动剔除 |
| 批量出包 | ZIP：每条广播一个 WAV（按线路/站点归目录）+ `manifest.json`（站点、触发条件、质检数据）+ `qa-report.md` |

## 核心实现

### 1. 三语调选条
`src/engine/compiler.ts` 的 `positionForVar` 按变量（或短语）在 token 序列中的位置选 `head / mid / tail`；句首升调、句中平调、句尾降调（`src/audio/synth.ts`），真实录音替换后同样按位置取条。

### 2. 中英文两套模板
模板带 `lang` 字段，全线编译时每个启用模板按语言各产出一条；变量渲染区分中文站名 / 大写英文站名、`十号线` / `Line 10`。

### 3. 拼接点自动选取（`src/audio/splice.ts`）
- 在两段词条相邻边界各 30ms 搜索窗内枚举上升沿过零点；
- 候选按**局部能量最低**排序、同能量级取电平跳变最小；
- 原始跳变超阈值（默认 -40 dBFS，可在工程设置调）时启用**等功率交叉淡化**（默认 6ms），再实测淡化后跳变并写入质检结果。

### 4. 句间停顿按标点规则
工程设置中维护标点 → 秒数规则表（句号 0.45s、逗号 0.25s 等，中英文标点各一套），编译器在 token 之间写入对应静音采样；句末标点的停顿落在整条尾部。

### 5. 临时运营图
甩站 / 改线计划含 `startAt / endAt`，编译时只纳入启用且未过期的计划，产出的广播带 `temporary.planName / activeWindow`，审核页与出包清单均标出生效时段。

### 6. 停站时长红线
每条广播编译时与该站 `dwellSeconds` 比较，`duration > dwell` 即 `overDwell=true`，审核页整行标红并显示超出秒数；出包默认排除问题条目（可手动包含）。

### 7. 噪声模型与清晰度指数
- `src/audio/noise.ts`：白噪经倍频程峰值整形（低频隆隆声）+ 带通限带，按 dBA 校准到目标 RMS；三档预设 62 / 68 / 75 dBA。
- `src/audio/intelligibility.ts`：简化 ANSI S3.5 倍频程法，250Hz–4kHz 五带测 SNR（截断 +30..-12dB），按标准权重加权得 AI，评级优 / 良 / 一般 / 差。

### 8. 出包元数据
`manifest.json` 每条含所属线路、站点（中英文名）、触发场景与**触发条件文字**、临时计划生效时段、拼接点逐点跳变、峰值电平等。

## 目录结构

```
src/
  audio/        音频内核：合成、滤波、拼接、噪声、清晰度、WAV、词条注册表
  engine/       编译器（模板→PCM）与出包器
  store/        zustand 持久化状态（配置数据；PCM 只存内存）
  pages/        六个页面
  components/   波形画布、卡片、设置弹窗、Toast
  __tests__/    vitest 测试
```

## 测试覆盖

- `splice.test.ts`：合成词条接缝跳变低于阈值；最坏直流跳变触发交叉淡化并压到阈值下；接缝邻域无爆音；停顿静音准确；三语调可区分。
- `compiler.test.ts`：分词、语调选条、标点停顿、超时标红、全线中英文编译、临时广播生效/过期/停用。
- `intelligibility.test.ts`：噪声 dBA 校准误差、安静环境 AI 显著高于嘈杂环境、权重和为 1。
- `packager.test.ts`：ZIP 内 WAV 数量与广播数一致（防文件名碰撞）、WAV 头、manifest 站点与触发条件。

## 已知边界

- 假词条为谐波+噪声合成的伪语音，用于验证拼接管线与听感差异，不替代真人录音；
- AI 为教学级简化模型（倍频程法），未做耳道传输函数与语音谱掩蔽修正；
- 状态持久化在浏览器 localStorage，音频 PCM 仅存内存，刷新后按配置即时重合成。
